# 🔍 URL Content Analyzer

A lightweight web application built using **HTML, CSS, Flask, and Regular Expressions (Regex)** to analyze content extracted from a given URL. The project demonstrates basic web development, backend integration, and text processing using Python.

## 🚀 Features

* **URL Input:** Enter a URL to analyze its content.
* **Content Analysis:** Process extracted content using Python.
* **Regular Expressions:** Use regex patterns to identify and analyze specific text patterns.
* **Web Interface:** Simple and user-friendly interface built with HTML and CSS.
* **Flask Backend:** Handle requests and process data on the server side.

## 🛠️ Tech Stack

| Technology                  | Purpose                            |
| --------------------------- | ---------------------------------- |
| HTML                        | Structure of the web interface     |
| CSS                         | Styling and layout                 |
| Python                      | Backend logic and text processing  |
| Flask                       | Web framework and request handling |
| Regular Expressions (Regex) | Pattern matching and text analysis |
